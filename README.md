
# User Card App 🪪

A simple web app that fetches random user data 
from an API and displays it on screen.

##  Built With
- HTML
- CSS
- JavaScript
- Fetch API
- Async/Await

##  Features
- Click a button to get a random user
- Shows user name, email and profile picture
- Uses real API data

##  Live Demo
[Click here to see live] https://github.com/Sami-devs/user-card_app/blob/main/smallproject.html

##  What I Learned
- How to use Fetch API
- How Promises work
- How to use Async/Await
- How to use response.json()

##  How to Run
1. Clone the repository
2. Open index.html in browser
3. Click "Get User" button
